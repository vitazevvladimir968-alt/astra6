# Astra 6 — сервер без регистрации

Фронтенд Astra 6 теперь не использует Puter и не просит пользователя входить в сторонний аккаунт. Имя и возраст сохраняются локально в браузере; телефон, почта и пароль для пользователя не нужны.

## Что осталось настроить владельцу

GitHub Pages не может безопасно хранить секретный API-ключ ИИ, поэтому для `/api/chat` и `/api/image` нужен сервер. В репозитории уже есть `worker.js` и `wrangler.toml` для Cloudflare Workers.

1. Создайте Cloudflare Worker.
2. Загрузите `worker.js` как код Worker.
3. Добавьте секрет `OPENAI_API_KEY`.
4. Добавьте переменную `OPENAI_MODEL` с моделью, доступной вашему API-проекту.
5. При желании задайте `OPENAI_IMAGE_MODEL`; по умолчанию используется `gpt-image-2`.
6. После публикации Worker получите его URL вида `https://astra6-api.<ваш-домен>.workers.dev`.
7. В `app.js` замените пустой `API_BASE` на этот URL.

### Почему ключ не кладём в app.js

Ключ, записанный в JavaScript GitHub Pages, будет виден любому посетителю. Сервер хранит его скрытым и сам обращается к API.

### Ограничение для бесплатного режима

Сервер содержит базовый лимит запросов без регистрации: до 20 запросов в час на IP в пределах одного экземпляра Worker. Это не полноценная защита от злоупотреблений, но лучше, чем открытый API без ограничений.

## Важно

Astra 6 не передаёт возраст пользователя на сервер. Возраст нужен только для локального профиля. Имя используется локально для персонализации системного сообщения Джарвиса.
