# Астра 6

Бесплатный AI-чат для телефона. Модель запускается прямо в браузере через WebLLM/WebGPU, без собственного API-ключа и платного сервера.

## iPhone
Откройте сайт в Safari → Поделиться → На экран «Домой» → Добавить.

При первом запуске браузер скачивает модель; после этого ответы генерируются на устройстве. Поддержка WebGPU и скорость зависят от устройства и браузера.
